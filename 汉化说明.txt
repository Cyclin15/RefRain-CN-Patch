RefRain - prism memories - 简体中文汉化补丁
================================================

适用版本 : Steam 版 V1.03.7 (RefRain.exe 大小 1,118,160 字节)
系统要求 : 简体中文区域设置的 Windows (系统代码页 GBK / 936)
补丁内容 : 游戏内全部 949 行文本汉化 (943 行译文 + 6 行原文即为空/乱码彩蛋)
           外加启动配置工具 config.exe 的界面汉化 (可选)

【安装方法】
1. 解压本压缩包内的所有文件到游戏根目录
   (即 RefRain.exe 所在的目录，保留 Patch 文件夹结构)
2. 双击运行「安装exe补丁.bat」
   它会自动把原版 RefRain.exe 备份为 RefRain.exe.bak，
   然后修改主程序中的 1 个字节 (字体字符集 日文→简体中文)。
3. 启动游戏即可看到中文。

【可选：汉化启动配置工具 config.exe】
- 双击运行「安装config补丁.bat」即可把 config.exe 的设置界面
  (画面尺寸、音量、手柄、Twitter 等全部选项) 汉化为中文。
- 这一步需要安装 Python 3 (https://www.python.org/，
  安装时勾选 "Add python.exe to PATH")。没有 Python 也不影响
  游戏本体汉化，只是配置工具保持原样。
- 原文件会备份为 config.exe.bak。

【卸载方法】
- 删除 Patch\patch_0001.rp1
- 把 RefRain.exe.bak 改名回 RefRain.exe
  (或通过 Steam 校验游戏文件还原主程序)
- 若安装过 config 补丁：把 config.exe.bak 改名回 config.exe

【常见问题】
- 游戏内文本乱码/方块 : 请确认系统区域为简体中文。
  本补丁依赖 GBK 代码页，非中文区域设置下无法正常显示。
- 运行 bat 提示版本不符 : 本补丁仅支持 V1.03.7 版主程序。
- Steam 校验文件会还原主程序，重新运行一次 bat 即可。
- config 补丁提示"未找到 Python" : 安装 Python 3 后重试，
  或跳过此步 (不影响游戏本体)。
